# 🎬 Indian Short Films (OTT Platform)

A full production-ready OTT discovery & streaming platform dedicated to showcasing independent Indian short films across all regional languages (Hindi, Gujarati, Tamil, Telugu, Malayalam, Kannada, Marathi, Bengali, Punjabi, English, and more).

---

## 🏗️ Architecture & Monorepo Structure

```text
indian-short-films/
├── apps/
│   └── capacitor_app/           # Android & iOS Mobile Application (Capacitor JS)
├── public_html_extracted/       # Web Application & API Backend (PHP, HTML, CSS, JS)
├── database/                    # MySQL Database schema & seed files
├── .gitignore                   # Git Ignore Configuration
└── README.md                    # Main project guide
```

## 🛠️ Technology Stack

- **Backend & API:** PHP (Native), MySQL
- **Frontend (Web):** HTML5, Vanilla CSS (Glassmorphism UI), Vanilla JavaScript
- **Mobile Apps (Android & iOS):** Capacitor JS (Native bridging)
- **Deployment (Web):** cPanel / Shared Hosting (Hostinger, etc.)
- **Deployment (Mobile):** Google Play Console & Apple App Store Connect

## 🚀 Features

- **Film Discovery:** Browse and watch short films in multiple Indian regional languages.
- **Filmmaker Submissions:** Independent creators can submit their films/reels directly through the app.
- **User Profiles & Watchlists:** Manage your saved films, track your submissions, and upload avatars.
- **Admin Dashboard:** Full control over content moderation, film uploads, and user management.
- **Promotor Portal:** Dedicated dashboard for promotors to manage and onboard their assigned creators.
- **Responsive Premium UI:** A dynamic, glassmorphism-based design that feels smooth and professional on all devices.
